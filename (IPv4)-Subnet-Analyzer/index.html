Pengertian IP Address

IP Address adalah sebuah pengalamatan yang berfungsi untuk menghubungkan komputer dalam suatu jaringan.

Pembagian Kelas IP Address

  • Kelas A = (0 - 127) 1 - 126
    • 0 : IP Network (IP Batasan yang diberikan oleh router)
    • 127 : IP Loopback (IP yang tertanam dalam perangkat / IP yang mengenali dirinya sendiri)
  • Kelas B = 128 - 191
  • Kelas C = 192 - 223
